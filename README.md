# MUKI SACCO Website

**A modern digital platform for MUKI SACCO.**

The MUKI SACCO Website is a responsive web application built to improve the SACCO's online presence and provide members and visitors with easy access to information about its financial products, services, membership, and digital banking solutions.

🌐 **Live Website:** https://muki-sacco-website-rkvd.vercel.app/

## Features

- **Home:** Introduction to MUKI SACCO and its services.
- **About Us:** SACCO background, history, mission, and vision.
- **Our Team:** Board of directors and management information.
- **Savings:** Available savings products.
- **Loans:** Information about different loan products.
- **Membership:** Membership information and registration guidance.
- **Digital Banking:** Mobile banking, ATM services, USSD, and Paybill information.
- **App Self Registration:** Guidance for members registering through the mobile application.
- **Insurance:** Information about MUKCOP insurance services.
- **Gallery:** Photos and visual content showcasing SACCO activities.
- **Contact:** Contact details and branch information.
- **Loan Calculator:** Interactive loan repayment estimation.
- **MUKI Chatbot:** Frontend-based chatbot to help visitors navigate the website and access information.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/fellyke/muki-sacco-website.git
```

### 2. Navigate to the project folder

```bash
cd muki-sacco-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

## Production Build

Generate an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Deployment

The website is deployed through Vercel and connected to GitHub for version control and deployment updates.
